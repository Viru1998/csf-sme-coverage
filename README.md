# CSF 2.0 SME Coverage Analysis

**Measuring the threat-informed effectiveness of NIST Cybersecurity Framework 2.0 for small and medium enterprises (SMEs), using MITRE ATT&CK and empirical incident data.**

A reproducible Python pipeline that quantifies how well NIST CSF 2.0 Subcategories address the ATT&CK techniques observed in real SME cyber incidents. Joins NIST CSF 2.0 to MITRE ATT&CK via a two-step bridge (CSF → NIST SP 800-53 Rev 5 → ATT&CK) using open mappings, weights techniques by Verizon 2026 DBIR SMB breach frequencies, and overlays MTU/NCSC 2025 Irish SME adoption gap data to produce a jurisdiction-specific priority ranking.

Companion code for the MSc Cybersecurity practicum dissertation at the National College of Ireland (2026).

---

## Key findings

- **Concentration.** Under greedy set-cover, one Subcategory (`PR.DS-01`, Data at Rest Protection) captures approximately 97% of the total SME threat weight.
- **Rank-1 for Irish SMEs.** `PR.IR-01` (Networks and environments protected from unauthorized access) is the rank-1 recommendation under the combined double-witness priority metric, aligned with NIS2 Article 21(2)(e).
- **Structural under-valuation.** Threat-informed coverage analysis structurally under-values the Govern and Respond CSF Functions, where Irish SMEs have the largest adoption gaps.
- **European corroboration.** 62.1% of the SME weight falls under four of the seven ENISA 2024 prime EU threat categories.

Full findings and the priority ranking are in [`outputs/FINDINGS_SUMMARY.md`](outputs/FINDINGS_SUMMARY.md).

## Quick start

```bash
# 1. clone
git clone https://github.com/<your-username>/csf-sme-coverage.git
cd csf-sme-coverage

# 2. create the pinned Conda environment
conda env create -f environment.yml
conda activate csf-sme-coverage

# 3. install the project package in editable mode
pip install -e .

# 4. run the full pipeline (approximately 7 seconds)
python -m csf_sme_coverage.cli

# 5. inspect the results
ls outputs/
cat outputs/FINDINGS_SUMMARY.md
```

The pipeline is deterministic — the same raw data always produces the same CSVs and figures.

## Pipeline

Seven phases, single command, roughly seven seconds end-to-end:

```
1. INGEST      → load 8 raw sources (CSF 2.0, ATT&CK, mappings, empirical PDFs)
2. BRIDGE      → join CSF → 800-53 → ATT&CK (9,011 pairs)
3. FILTER      → restrict to SME-relevant techniques (662 rows)
4. SCORE       → raw + weighted + marginal coverage; greedy set-cover
5. IRISH OVERLAY → double-witness priority using MTU/NCSC 2025 gap data
6. VISUALISE   → 5 publication-quality figures
7. REPORT      → 8 CSVs + FINDINGS_SUMMARY.md
```

Individual phases can be run from any directory once the package is installed:

```bash
python -m csf_sme_coverage.ingest
python -m csf_sme_coverage.bridge
python -m csf_sme_coverage.score
# ... and so on
```

## Data sources

Every source is open, free to download, and version-pinned in the repository.

| Source | Purpose | Reference |
|---|---|---|
| NIST CSF 2.0 (CSWP 29) | Framework backbone | [DOI:10.6028/NIST.CSWP.29](https://doi.org/10.6028/NIST.CSWP.29) |
| NIST SP 800-53 Rev 5 | Control catalogue | [NIST SP 800-53r5](https://nvlpubs.nist.gov/nistpubs/SpecialPublications/NIST.SP.800-53r5.pdf) |
| NIST OLIR #186 Crosswalk | CSF ↔ 800-53 (draft) | [csrc.nist.gov](https://csrc.nist.gov/projects/olir/informative-reference-catalog) |
| MITRE ATT&CK Enterprise v16.1 | Threat catalogue | [attack.mitre.org](https://attack.mitre.org/) |
| CTID 800-53 → ATT&CK | Bridge mappings | [Center for Threat-Informed Defense](https://github.com/center-for-threat-informed-defense/mappings-explorer) |
| Verizon DBIR 2026 | SMB incident weights (n=7,152) | [verizon.com/dbir](https://www.verizon.com/business/resources/reports/dbir/) |
| ENISA Threat Landscape 2024 | EU corroboration | [enisa.europa.eu](https://www.enisa.europa.eu/topics/cyber-threats/threats-and-trends) |
| MTU / NCSC 2025 | Irish SME adoption gaps (n=894) | [Munster Technological University / NCSC Ireland](https://www.mtu.ie/) |
| NCSC Ireland 2025 | SME core measures | [ncsc.gov.ie](https://www.ncsc.gov.ie/) |

## Reproducibility

- All library versions are pinned in `environment.yml`.
- The pipeline uses a fixed random seed and produces bit-identical outputs on repeat runs.
- End-to-end runtime: approximately 7 seconds on a 2020-era laptop.
- Tested on Windows 11, macOS 14, and Ubuntu 22.04.
